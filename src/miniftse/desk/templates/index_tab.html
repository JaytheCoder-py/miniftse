Annualised return is compounded over calendar years (IndexHistory.annualised_return: (end / start) ** (1 / years) - 1, years = days / 365.25) - not the 252-trading-day convention some factsheets use. Annualised volatility scales the daily return standard deviation by √252 trading days. Divisor events counts every corporate-action and periodic-review divisor change in divisor_audit.parquet (len(history.divisor_audit)), the same figure Screen 1's event table is built from - these are the library's own published definitions, read straight off overview.json["stats"], not recomputed here.
