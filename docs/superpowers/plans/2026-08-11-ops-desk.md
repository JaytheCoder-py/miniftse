# Ops Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `desk/`, a FastAPI application that exposes the *working* parts of
miniftse on the web — the divisor audit trail, the fault-injection drill against the
validation engine, the methodology assistant with its eval harness and number guard, the
golden master, and the index itself — so a visitor can see the platform operate rather
than only see its output.

**Architecture:** One library addition (`ValidationContext.save`/`load`) removes the only
blocker to serving the chaos drill from a web request. A snapshot builder runs the
reference index once at build time and writes every historical artefact the app needs to
`desk/data/`, which is committed. The FastAPI app loads that snapshot into a frozen
dataclass at startup and serves five screens from memory, with two cheap live paths (the
validation engine, and BM25 retrieval against the offline LLM backend). Server-rendered
Jinja2 with HTMX fragments; no npm, no bundler, no build step.

**Tech Stack:** Python (existing `miniftse` package, `uv`, `pytest`), FastAPI + uvicorn,
Jinja2 (already a dependency), HTMX and Chart.js via pinned CDN `<script>` tags, Docker
(existing `Dockerfile`), Hugging Face Spaces for hosting.

## Global Constraints

- **No `build_index` call on any request path.** Everything historical is precomputed by
  `make desk-data` and committed (spec: Data pipeline). A test asserts startup completes
  in under two seconds.
- **No index mathematics, validation logic or retrieval logic in `desk/`.** The web layer
  does HTTP, HTML and bounded concurrency; every number comes from a library call
  (spec: Architecture). Task 14 enforces this with a test.
- **Offline LLM by default.** `MINIFTSE_LLM` defaults to `offline` → `OfflineLlm`
  (`src/miniftse/agents/llm.py:69-145`). No key, no network, no spend in the deployed
  container (spec: Audience & hosting).
- **No npm, no frontend build step.** Plain templates plus two pinned CDN scripts
  (spec: Backend).
- **Every user input validated against a closed set** before reaching a library call; a
  bad value is a 400, never an exception (spec: Security).
- **Snapshot missing or malformed at startup → refuse to start**, naming the file
  (spec: Error handling).
- Index id is `MFTSE-GLOBAL` (`src/miniftse/config.py`, `IndexConfig` default), matching
  the capacity-viz plan.
- `desk/data/` is generated-but-tracked, exactly as `artefacts/` already is.
- Prerequisite: the `adv` threading from `2026-08-11-capacity-viz` Tasks 1–4 must be
  merged before Task 12 here (Screen 5 reads `adv` from the state file). Tasks 1–11 do
  not depend on it.

    ctx.save(tmp_path / "baseline")
    back = ValidationContext.load(tmp_path / "baseline")

    assert back.as_of == ctx.as_of
    assert back.divisor == ctx.divisor
    assert back.prior_divisor == ctx.prior_divisor
    assert back.index_level == ctx.index_level
    assert back.total_market_value == ctx.total_market_value

    pd.testing.assert_series_equal(back.weights, ctx.weights)


def test_validation_context_round_trips_none_fields(tmp_path):
    """Absent frames must come back absent, not as empty DataFrames.

    An empty frame and a missing frame mean different things to the rules: several
    checks in `quality/checks.py` short-circuit to a pass when their input is None and
    would report a spurious failure against an empty frame.
    """
    ctx = _context()
    ctx.save(tmp_path / "b")
    back = ValidationContext.load(tmp_path / "b")
    assert back.corp_actions is None
    assert back.alternate_source is None
    assert back.fx is None


def test_loaded_context_passes_the_same_rules(tmp_path):
    """The real acceptance criterion: same findings before and after a round trip."""
    from miniftse.quality.rules import ValidationEngine

    ctx = _context()
    engine = ValidationEngine.default()
    before = engine.run(ctx, run_id="before").to_frame()
    ctx.save(tmp_path / "b")
    after = engine.run(ValidationContext.load(tmp_path / "b"), run_id="after").to_frame()

    pd.testing.assert_frame_equal(
        before.drop(columns=["run_id"], errors="ignore"),
        after.drop(columns=["run_id"], errors="ignore"),

- [ ] **Step 3: Implement `save` / `load`**

In `src/miniftse/quality/rules.py`, add to `ValidationContext`. Write out each frame as
parquet under `directory/`, named for its field; write the scalars, the `constituents`
keys and the config name to `directory/meta.json`. Absent fields must be **omitted from
meta and have no parquet file**, so `load` can distinguish "missing" from "empty".

Sketch — adapt names to the actual field list at `rules.py:156-178`:

```python
    _FRAME_FIELDS = ("prices", "prior_prices", "shares", "corp_actions",
                     "divisor_audit", "reference", "alternate_source", "fx", "prior_fx")
    _SCALAR_FIELDS = ("index_level", "prior_index_level", "divisor", "prior_divisor",
                      "total_market_value", "official_level")

    def save(self, directory: Path) -> Path:
        """Persist this context so a validation run can be reproduced without rebuilding
        the index that produced it.

        The alternative — re-running `build_index` to reconstruct a context — is what
        `cli.chaos_drill_cmd` does today, and it costs tens of seconds. That is fine for
        a terminal command and impossible inside a request.
        """
        directory = Path(directory)
        directory.mkdir(parents=True, exist_ok=True)
        present: list[str] = []
        for name in self._FRAME_FIELDS:
            frame = getattr(self, name)
            if frame is not None:
                frame.to_parquet(directory / f"{name}.parquet", index=False)
                present.append(name)
        if self.weights is not None:
            self.weights.rename("weight").to_frame().to_parquet(
                directory / "weights.parquet"
            )
            present.append("weights")
        meta = {
            "as_of": self.as_of.isoformat(),
            "present": present,
            "scalars": {f: getattr(self, f) for f in self._SCALAR_FIELDS},
            "constituents": list(self.constituents),
            "config": type(self.config).__name__ if self.config is not None else None,
        }
        (directory / "meta.json").write_text(json.dumps(meta, indent=2))
        return directory
```

`load` is the mirror: read `meta.json`, read only the parquet files named in `present`,
rebuild `weights` as a Series from its single column, restore scalars, rebuild
`constituents` as `dict.fromkeys(...)` (matching `build_baseline_context`'s own
construction at `faults.py:405`), and resolve `config` by name from `miniftse.config`.

Add `import json` and `from pathlib import Path` if not already present.
